## Agent 与知识管理

### Agent 驱动 Obsidian

让 Agent 协助读取笔记、整理输入、经确认后写入，并持续维护 Obsidian 知识库；继续使用用户自己的 Vault 与同步方式。

### 长期项目管理

用任务、里程碑、检查点和状态文件保存项目进展，使其能在跨会话、中断或更换执行者后继续恢复。

### 模型额度路由

在新模型发布、额度有限时，按任务难度、风险、可验证性和返工成本安排模型与分工。

## 专题工作流

### 民商事案件分析

从案件事实出发，梳理主体关系、请求权、抗辩、期间与程序问题。

### 案例检索

把具体问题转化为可复核的法规、案例、裁判规则与待确认事项。

### 民事诉讼模拟法庭

从法官与对方律师视角检查现有方案，找出事实、证据、逻辑与法律依据中需要补强的部分。

### 诉讼可视化

将关系、时间线、证据链、金额计算和争点整理成更容易核验的图表或页面。
